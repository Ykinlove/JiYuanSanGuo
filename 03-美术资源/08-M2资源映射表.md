# M2 美术资源映射表

> 用途：记录贴图与游戏内元素的对应关系。美术资源就绪后，把文件放入 `04-Demo/assets/sprites/` 对应路径，
> 游戏即**自动切换为贴图渲染，无需改代码** —— `TerrainPainter`、`EncounterManager`、`NPCManager`、
> `PlayerController` 都会在启动时检测同名文件，存在则用贴图，缺失则回退程序化绘制。
>
> **命名铁律**：遭遇与 NPC 的贴图文件名必须与其 JSON 中的 `id` **完全一致**（含下划线），否则检测不到。

## 七、接入方式

美术文件放入对应目录后**无需改代码**，各系统会在启动时自动检测：

| 系统 | 检测目录 | 文件名规则 | 回退方案 |
| --- | --- | --- | --- |
| `TerrainPainter` | `assets/sprites/terrain/` | `{地形id}.png` | 程序化地形多边形绘制 |
| `EncounterManager` | `assets/sprites/encounters/` | `{遭遇id}.png` | 几何菱形 + 名称标签 |
| `NPCManager` | `assets/sprites/npcs/` | `{npc_id}.png` | 几何小人 + 脚下投影 |
| `PlayerController` | `assets/sprites/player/` | `walk.png`（4行×4帧） | 几何小人 + 行走起伏 |

检测同时支持 `.png` 与 `.webp`。

> 当前 M2 使用**程序化绘制**作为占位，视觉已具备地貌层次感（山林/水泽/道路/装饰），
> 贴图就绪后替换即可获得正式画面。

## 八、音频资源规划（`assets/audio/`）

> 与美术同步推进。文件名同样会被 `AudioManager` 按路径加载。

| 类别 | 文件名 | 用途 | 时长 |
| --- | --- | --- | --- |
| BGM | `bgm_main_menu.ogg` | 主菜单 | 60~90s 循环 |
| BGM | `bgm_world.ogg` | 大地图探索 | 90~120s 循环 |
| BGM | `bgm_city.ogg` | 城池内 | 60~90s 循环 |
| BGM | `bgm_battle.ogg` | 战斗 | 90~120s 循环 |
| BGM | `bgm_boss.ogg` | 首领战 | 60~90s 循环 |
| SFX | `sfx_click.ogg` / `sfx_confirm.ogg` / `sfx_cancel.ogg` | UI 交互 | <1s |
| SFX | `sfx_hit.ogg` / `sfx_skill.ogg` / `sfx_victory.ogg` | 战斗反馈 | <2s |
| SFX | `sfx_gather.ogg` / `sfx_chest.ogg` / `sfx_levelup.ogg` | 事件反馈 | <2s |

> 格式统一用 **OGG Vorbis**（Godot 移动端最佳）；短音效用单声道，BGM 用立体声 128kbps。
