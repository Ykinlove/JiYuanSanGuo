## 10. AI 生成建议

### 10.1 推荐工具

| 工具 | 优势 | 适用 |
| --- | --- | --- |
| **Midjourney** | 画质最精美，风格统一 | 立绘、背景 |
| **Stable Diffusion + 国风 LoRA** | 可控性强，可批量 | 立绘、图标 |
| **即梦 / 通义万相** | 中文提示词友好，国产免费 | 快速出图 |
| **Nijijourney** | 二次元风格最强 | **立绘首选** |

### 10.2 出图流程建议

```
1. 先用 3–5 张测试图锁定风格（人物 + 背景各测一组）
2. 固定统一的后缀提示词（见 0.1 风格锚点）
3. 批量生成 → 筛选 → 用 Krita/GIMP 修整（抠图、统一色调）
4. 按规范尺寸裁切 → 切图 → 导入 Godot
5. 建立美术资源清单表格，记录每张图的生成参数（便于风格一致）
```

### 10.3 一致性技巧

- **固定角色描述**：每个角色写一段固定的"角色特征卡"，每次生成都带上
- **固定风格后缀**：所有图共用同一段风格词
- **参考图**：Midjourney 用 `--sref`（风格参考），SD 用 ControlNet
- **种子固定**：同一角色的多个姿态用同一 `--seed`
