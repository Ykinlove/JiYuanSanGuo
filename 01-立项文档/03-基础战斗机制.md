## 1. 战斗总体流程

```
大地图触发战斗
      ↓
【战前准备】查看双方情报 → 选择出战武将 → 编辑阵型 → 配置兵种
      ↓
【进入战场】实时战斗
   ├─ 玩家操作：主角移动/攻击/闪避/大招
   └─ 部队指挥：全军突击 / 分队进攻 / 固守 / 撤退
      ↓
【胜负判定】敌方全灭 or 士气归零 or 我方撤退
      ↓
【战后结算】经验/金钱/缴获/俘虏/伤亡
```

### 2.2 阵型编辑系统

**核心创新点**：这是对标大时代2的阵型概念、并做深化的系统。

> 📌 **本节的详细设计与实现规格已独立成文，见 `02-策划文档/10-阵型编辑器设计.md`**（M3 已实装）。
> 下文为立项阶段的框架定义，实现细节以该文档为准。

| 阵型 | 效果 | 适用 |
| --- | --- | --- |
| 鱼鳞阵 | 攻击 +15%，防御 −5% | 正面强攻 |
| 鹤翼阵 | 两翼包抄，侧击加成 | 包围 |
| 方圆阵 | 防御 +20%，移动 −10% | 防守待援 |
| 锋矢阵 | 冲锋伤害 +25%，士气消耗快 | 突击突破 |
| 长蛇阵 | 行军速度 +20%，接战弱 | 追击/撤退 |
| 鸳鸯阵 | 兵种混合，克制面广 | 通用 |

**编辑规则**：
- 战场划分为 **3×5 阵位网格**（前军/中军/后军 × 5 列），共 15 个阵位
- 玩家把每支部队放入阵位（点击式：选部队 → 点阵位）
- **每个阵位有独立的攻防加成**（见下方阵位加成表）
- **行-兵种协同**：前军配步兵 / 中军配骑兵 / 后军配弓兵 有额外加成，反之有惩罚
- 阵型与兵种配合产生组合效果
- **实时战力预估**：每次摆位立即刷新我方战力、敌方战力、胜率百分比

| 前军·锋翼 | +15% | −10% | 包抄位 |

#### 行-兵种协同表（M3 实装）

| 行 | 适配兵种 | 加成 | 冲突兵种 | 惩罚 |
| --- | --- | --- | --- | --- |
| 前军 | 步兵 | 防御 +10% | 弓兵 | 攻击 −25% |
| 中军 | 骑兵 / 精英 | 攻击 +8% | — | — |
| 后军 | 弓兵 | 攻击 +15% | 骑兵 | 战力 −20% |

#### 战力公式（M3 实装）

```
单支部队战力 = 兵力 × (1+阵型攻击) × (1+阵位攻击) × (1+行协同)
              × 兵种品质 × 武将加成
兵种品质     = (attack + hp × 0.1) / 30
武将加成     = 1 + clamp((统率 − 50) / 200, −0.30, +0.30)
              （「中帐位」上此加成超出 1.0 的部分 ×2）
胜率预估     = Logistic(1.1 × ln(我方总战力 / 敌方总战力))
```

### 3.4 士气系统（关键，M4 已实装）

- 士气 0–100，初始 100
- 士气受挫有**三个来源**（缺一不可，否则部队总是先被打死、溃散机制形同虚设）：

| 来源 | 计算 | 设计意图 |
| --- | --- | --- |
| 伤害压力 | `本次伤害 / 最大血量 × 100 × 0.45` | 被强敌压着打，军心散得快 |
| 兵力压力 | `(1 − 残兵比) × 100 × 0.22` | 人越少越慌，接近全灭时剧烈下滑 |
| 持续压力 | 每次受击固定 `3.2` | 久战必疲，避免僵持局永不让士气下降 |

> 三个压力相加后乘以 `morale_decay_per_loss`（默认 1.6）× `0.5`。

- **士气 ≤ 18 → 该部队溃散**（退出战场，残兵不会被计入阵亡）
- **溃散判定先于阵亡判定**：兵败如山倒——人还在，但仗已经不想打了
- 脱战状态下士气缓慢恢复（`morale_recover_rate`，固守时 ×2）
- 击杀敌将会鼓舞全军士气；主角大招给全军 +15 士气
- 统帅流玩法：通过降敌方士气取胜（对标大时代3"张济可降双倍士气"）

**实装验证结论**（详见 `04-Demo/_verify_combat.py`）：
- **重甲部队**（藤甲兵 hp130/def45）第 8 次受击后**溃散，残兵 88/160** —— 这正是"兵败而非兵亡"的戏剧时刻
- **轻甲部队**（弓箭手 hp70）第 3 次受击就**战死** —— 脆皮单位来不及崩溃，符合兵种性格
- 这条对照说明：士气把"能不能扛"变成了战术变量——**上重甲拖住、用轻甲输出**成为真实可行的思路

#### 3.4.2 伤害公式（M4 实装）

```
单次伤害 = 攻击力 × 兵力系数 × (1 + 布阵加成 + 冲锋加成 + 固守惩罚)
           × 克制倍率 × 基础系数 × 10
           × 防御减伤 × (1 ± 随机浮动)

兵力系数   = clamp(残兵 / max(30, 初始兵力) × 0.7 + 0.3, 0.3, 1.0)
防御减伤   = clamp(1 − 防御 × 布阵防御加成 / 120, 0.35, 1.0)   # 保底 35%
冲锋加成   = +55%（持续 2.2 秒，移动速度 ×1.6）
固守效果   = 攻方固守：输出 −20% ；守方固守：受击 −35%
随机浮动   = ±25%（让每场战斗有差异，避免"算好必胜"）
最小伤害   = 1.0（防止 0 伤害死循环）
```

**兵力与血量双轨**：每次受击同时扣 `hp`（`−伤害`）和 `兵力`（`−ceil(伤害 × 0.55)`），
任一归零即阵亡。这让"精兵"和"人海"两种思路都能成立。

#### 3.4.3 部队 AI 行为（M4 实装）

固定步长 **0.25 秒一 tick**（与帧率解耦，避免高帧率下伤害漂移）。

```
状态机：IDLE → ADVANCE（推进）→ ENGAGE（交战）→ ROUTED（溃散）/ DEAD
```

**索敌评分**（每次 tick 重新评估，部队会自动换目标）：

| 因子 | 权重 | 说明 |
| --- | --- | --- |
| 距离 | ×1.2 | 近战必须够得着，优先打附近 |
| 克制关系 | ×0.55 | 优先打自己克制的兵种 |
| 残血优先 | ×0.45 | 优先收割残血部队（"痛打落水狗"） |
| 兵种偏好 | ×0.3 | 弓兵权重 1.35（优先切后排），象兵 0.85（肉盾留最后） |

**全军指令（M4 实装）**：

| 指令 | 效果 | 实测 |
| --- | --- | --- |
| 全军突击 | 所有存活部队冲锋，输出 ×1.55、移速 ×1.6 | 用于突破僵局 |
| 固守 | 转防御，全军士气 +12，攻 −20% / 受击 −35% | 用于拖住强敌 |
| 分队进攻 | 指定部队集中打最弱的敌人 | 集火收人头 |
| 撤退 | 强制结束战斗，按失败结算 | — |

**主角参战（M4 实装）**：

| 操作 | 效果 |
| --- | --- |
| 普攻 | 需在最近敌军 **260px 内**才命中，否则提示"距离过远" |
| 大招 | 怒气 ≥ 50 释放，打击最靠前两支部队（第二支 ×0.6），**全军士气 +15** |
| 闪避 | 0.6 秒无敌帧 |

> **实测结论**：主角大招把 3v3 战斗从 **48 tick 压缩到 36 tick**（约 12 秒 → 9 秒），
> 同时大幅提升友军士气——主角不只是"一个高攻单位"，而是战场的士气锚点。

## 7. 战斗结算

| 项目 | 内容 |
| --- | --- |
| 胜利条件 | 敌方全灭 / 敌将阵亡 / 敌士气归零 / 敌撤退 |
| 失败条件 | 我方全灭 / 主角阵亡 / 我方撤退（视为失败或逃脱） |
| 结算内容 | 经验、金钱、粮草、装备掉落、俘虏（可招降/处决/劳役）、伤亡统计 |
| 战后影响 | 势力关系变化、名声变化、城池归属 |

**俘虏处理**（对标大时代3）：
- 招降（需魅力/关系判定）
- 释放（提升名声）
- 处决（增加恶名）
- 劳役（去挖矿，比征兵划算）

### 7.1 补充：主角战败被俘规则

| 情形 | 判定与结果 |
| --- | --- |
| **主角部队全灭，主角未直接阵亡** | 有概率被敌方俘获；按**敌方君主性格**触发不同结果：<br>· 关押（可等待本方赎回或越狱）<br>· 招降（可选接受/拒绝）<br>· 直接释放 |
| **主角直接阵亡** | 若存在可赎回势力 → 触发**赎回剧情**，支付金钱/物资复活；<br>若被处决或无人赎回 → 触发 **Game Over**，退回最近存档 |
| **我方部队溃败，主角成功撤退** | 损失部分兵力、粮草与缴获物资，主角安全脱离战场，不损失存档 |

> 设计目标：让失败也有叙事重量，而非简单的"读档重来"。

### 8.1 M5 补充说明：演武场的战斗验证价值

M5 新增的「战役演练」模式（详见 `02-策划文档/12-城池经营与招募系统设计.md` §4.7）
给战斗系统提供了一个**零成本验证场**：

- **教学用途**：6 套预设各自针对一个机制 —— 如 `drill_cavalry_raid`（骑兵突袭）
  专门教"长枪兵克骑兵"，`drill_rattan_line`（藤甲铁壁）专门教
  "高防单位会溃散而非战死"这一 M4 的核心设计。
- **研发用途**：策划可在不改存档、不影响正式进度的前提下，
  反复验证新阵型/新兵种配置的战斗表现。
- **闭环链路**：官府 → 演武场 → 布阵界面（`drill_mode=true`）→ 战场（专属结算）
  → 返回布阵继续试摆。全程不触碰 `GameState.formation_slots` 与存档文件。
