## 2. 大地图玩法

### 2.1 自由行走

- 主角左摇杆控制方向，八方向移动
- 遭遇系统：踩到敌人图标/触发区 → 进入战斗
- 昼夜与天气在地图上可视表现

### 2.2 生活玩法（地图采集）

| 玩法 | 产出 | 说明 |
| --- | --- | --- |
| 钓鱼 | 食材、随机宝物（如避毒珠） | 水边按提示操作 |
| 采药 | 药材 | 山林地带 |
| 挖矿 | 铁矿、朱砂、矿石 | 矿洞/山体 |
| 打猎 | 兽皮、肉 | 野外 |
| 开宝箱 | 装备、金钱、任务道具 | 隐藏在各处 |

**关键设计**：这些"小事"是系列的灵魂之一，用来调节战斗节奏、给予探索奖励。

> **⚠️ 平衡约束**：钓鱼、采药、打猎等野外采集**设置每日次数上限**（建议每种每日 3–5 次），
> 且产出受**当地资源等级**影响。防止玩家无限刷取资源破坏经济平衡与成长曲线。

### 2.3 隐藏要素

- **隐藏资源点**（如毒龙潭 +猛毒箭、翡翠矿洞 解锁藤甲兵科技、巫医祭坛 伤病恢复×2）
- **隐藏通道**（如华佗身后密道、泰山监狱旁通道）
- **隐藏事件**（连续上香三次触发隐藏事件得虎符）

### 3.3 外交关系

| 关系值 | 状态 | 影响 |
| --- | --- | --- |
| 80~100 | 同盟 | 可借兵、通商、共同作战 |
| 30~79 | 友好 | 可贸易、可通行 |
| −29~29 | 中立 | 互不干涉 |
| −79~−30 | 敌对 | 可能袭击、拒绝对话 |
| −100~−80 | 死敌 | 主动宣战、追杀 |

**外交手段**：结盟、通商、宣战、联姻、离间、造谣、破坏。

> **⚠️ 势力 AI 开发约束**：势力 AI **仅处理高层全局决策** —— 征兵、攻城、结盟、宣战、招揽武将。
> **不做**武将微观操控，**不自动修改**武将装备与天赋加点，**不做**逐部队实时推演（用概率模型结算）。
> 目的：大幅降低开发复杂度，把精力集中在玩家可感知的核心体验上。

## 4. 城池体系

### 4.1 城池数据结构

| 字段 | 说明 |
| --- | --- |
| 等级 | 1–5 级，决定建筑位与产出上限 |
| 归属势力 | 控制方 |
| 驻军 | 守军兵力与武将 |
| 城防 | 城墙等级，影响守城战 |
| 民心 | 0–100，影响产出与叛乱 |
| 建筑 | 农田、商栈、兵营、学堂等 |
| 特产 | 本地资源（影响贸易） |
| 守将 | 驻守武将 |

### 4.2 内政建设（核心经营循环）

| 建筑 | 功能 | 产出/效果 |
| --- | --- | --- |
| **农田** | 产粮 | 粮草，等级越高产出越多 |
| **商栈** | 贸易 | 金钱，可买卖物资 |
| **兵营** | 征兵/练兵 | 提升兵种等级，招募士兵 |
| **学堂** | 科技/人才 | 研发科技、培养人才 |
| **铁匠铺** | 装备 | 锻造武器、强化装备 |
| **医馆** | 治疗 | 恢复伤兵、治疗主角 |
| **城墙** | 防御 | 提升城防等级 |
| **市场** | 交易 | 物价波动、物资买卖 |
| **驿站** | 交通 | 快速移动 |

**科技树**（分段发展）：
- 农业线：粮食产出、人口增长
- 军事线：兵种解锁、兵种等级、攻防加成
- 医农线：采药术、伤病恢复（前期保命符）
- 商业线：贸易效率、物价控制

> **粮草负数惩罚**：当城池 / 部队粮草为负时，**每日发生士兵大量逃亡**（按负值比例扣减兵力），同时**城池民心持续下降**。这是约束玩家无脑暴兵、逼迫经营农田的核心机制。

#### 4.2.1 已实装的建筑（M5）

上表是长期规划。**M5 已实装其中 5 座建筑**，采用「五建筑 + 抽屉面板」结构，
详见 `02-策划文档/12-城池经营与招募系统设计.md`：

| 建筑 | 键 | M5 已实装功能 | 数据源 |
| --- | --- | --- | --- |
| 酒馆 | `tavern` | 武将招募（明码标价 + 名声/恶名双轨）、赠礼交好 | `recruit_pool.json` |
| 兵营 | `barracks` | 征兵（14 兵种四重门禁）、练兵升级、任命统兵武将 | `barracks.json` |
| 市场 | `market` | 买卖资源（粮/木/铁）、买卖消耗品 | `shop_goods.json` |
| 铁匠铺 | `smith` | 购置装备（按城池等级 + 区域解锁） | `shop_goods.json` |
| 官府 | `hall` | 开仓施赈（民心）、修缮城防、**进入演武场** | `drill.json` |

**建筑开放规则**：`cities.json` 的 `buildings` 数组决定该城开放哪些建筑，
官府常开。因此同一套城池界面可适配全部 11 个地点：

- 建宁（3 级城，`["farm","market","barracks","smith"]`）→ 五建筑全开
- 阿乡寨（村寨，`["farm"]`）→ 只开放官府
- 泸水渡口（关隘，`[]`）→ 只开放官府

**尚未实装**：农田、学堂、医馆、城墙、驿站将在后续里程碑接入。

#### 4.2.2 民心机制（M5 实装，重要调整）

原方案「民心」只影响产出与叛乱，缺少可感知的即时反馈。
M5 将其改造为**征兵系统的真实瓶颈**：

```
民心消耗 = ceil(征募人数 / 10) × 2
民心可征容量 = floor((当前民心 - 下限30) / 2) × 10
实际可征上限 = min(每日名额, 民心可征容量)
```

| 城池 | 民心 | 民心上限 | 每日名额 | 实际可征 | 卡在哪 |
| --- | --- | --- | --- | --- | --- |
| 建宁 | 70 | **200 人** | 300 人 | 200 人 | 民心 |
| 云南 | 72 | 210 人 | 180 人 | 180 人 | 名额 |
| 滇池城 | 68 | 190 人 | 160 人 | 160 人 | 名额 |
| 牂牁 | 70 | 200 人 | 170 人 | 170 人 | 名额 |
| 永昌 | 65 | 170 人 | 200 人 | 170 人 | 民心 |
| **五城合计** | — | — | — | **880 人** |

**设计效果**：民心与每日名额形成**双约束互补** ——
大城（建宁、永昌）先撞民心墙，中城（云南、滇池、牂牁）先撞名额墙，
玩家在不同城池要面对不同的扩张瓶颈，比"处处都卡民心"更有层次。
民心触底（≤30）后征兵通道**自动关闭**，形成天然节奏：
`征兵 → 民心下降 → 触底 → 施赈或等日推 → 恢复 → 继续扩军`。

施赈成本 `-金 200 → 民心 +5`（约 25 兵额度），
明显贵于直接征兵（25 兵仅需 100 金），因此**施赈是应急手段而非刷兵途径**。

> **待确认**：`3 点/10兵` 是否偏紧？若手感太紧可降到 2 点（建宁 → 195 兵）。

### 4.3 攻城战

```
发起攻城 → 守方城防加成 → 攻城方需破门/翻墙
   → 城中巷战 → 占领官府 → 城池易主
```

**要素**：
- 攻城器械：冲车、云梯、投石车
- 城防等级影响破门难度
- 里应外合（内应/离间降低城防）

## 5. 自立为王机制

对标大时代4/6，完整流程：

### 5.1 前提条件
1. **未加入任何势力**（保持平民身份）
2. 积累足够声望

### 5.2 声望公式（参考大时代6）

```
自立判定值 = 村庄声望 + 自身名声 − 自身恶名
自立阈值 ≈ 160
```

**声望获取**：
| 方式 | 效果 | 备注 |
| --- | --- | --- |
| 完成村民/酒店老板委托 | 村庄名声 +1 | 注意：接任务后需等 3 日以上交付才计数 |
| 野外消灭山贼/黄巾 | 自身名声 +1（上限100） | 主要途径 |
| 打劫 | 恶名 +1（上限100） | **不建议**，负增长 |

### 5.3 立业流程
```
完成任务链（示例：云南焚乐塔找文子 → 峨眉山寻老朵 → 泰山救水寿 → 找龙眼）
   → 收集建国信物：玉玺 + 虎符
   → 在祠堂/指定城池触发自立剧情
   → 选择旗帜 + 输入势力名
   → 该村庄/城池升格为都城 → 自立成功
```

### 5.4 自立后
- 可设国号、旗帜、君主称号
- 开始与其他势力正面博弈
- 解锁自立专属剧情线与结局

> **⚠️ Demo 边界说明**：**南中 Demo 版本不实现完整自立称王全流程**。自立为王归属**第三阶段全量内容**；Demo 仅可接取势力委托任务与村镇任务，**无法建国立国**。

## 6. 任务系统

### 6.1 任务类型

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| **主线** | 历史事件推进 | 董卓废帝、官渡、赤壁 |
| **势力任务** | 加入势力后专属 | 为曹操取徐州 |
| **支线** | 人物专属剧情 | 张飞找赤珠山铁、黄忠找虎筋 |
| **委托** | 村镇日常 | 村长/酒店老板委托 |
| **隐藏** | 触发式 | 香波公主剧情、诸葛亮相助 |
| **生活** | 采集类 | 钓鱼、采药任务 |

### 6.2 多分支对话（六角菜单）

- 对话选项呈**六角形**排列（系列特色）
- 选项影响：人物关系、任务走向、结局分支
- 特殊选项：**求婚**（需亲密度达标）
- **属性门槛**：部分选项设置属性门槛（魅力 / 名声 / 声望不达标），**不满足条件的选项置灰，不可点击**，并显示所需条件提示

### 6.3 亲密度系统

| 行为 | 效果 |
| --- | --- |
| 完成任务 | +亲密度 |
| 送礼 | +亲密度（按喜好） |
| 对话选择得当 | +亲密度 |
| 与女性角色亲密度达标 | 解锁求婚选项 |
| 失败/选错 | −亲密度（如用牛筋充虎筋会被黄忠识破） |

## 7. 武将系统

### 7.1 武将数据结构

| 字段 | 说明 |
| --- | --- |
| 姓名 / 字 | 如 关羽 / 云长 |
| 四维 | 体质、力量、智力、魅力 |
| 等级 / 经验 | 成长 |
| 技能 / 特技 | 专属技能 |
| 装备 | 武器、铠甲、坐骑 |
| 兵种适性 | 擅长带什么兵 |
| 亲密度 | 与主角关系 |
| 列传 | 生平介绍（系列特色） |

### 7.2 招募方式

| 方式 | 说明 |
| --- | --- |
| 剧情招募 | 任务中结识 |
| 招降 | 击败后招降（需魅力/关系，敌方仅剩一城时成功率提升） |
| 送礼/结识 | 提升魅力与关系 |
| 势力分配 | 加入势力后由主公指派 |
| 命运召唤 | 命运人物（系列特色） |

### 7.3 培养

- 升级 → 属性点 + 天赋点
- 装备锻造、宝石镶嵌、宝物升金
- 亲密度解锁专属剧情与技能
