## 3. 核心体验支柱（Design Pillars）

这是所有设计决策的最高准则。任何功能若不能服务于这四根支柱，就应当砍掉。

### 支柱一：**自由** —— "我想成为谁，由我决定"

- 玩家从一个无名之辈开始，没有强制主线锁死。
- 三条大的路径：**投靠势力**（当将领）/ **自立为王**（创业）/ **游侠商人**（游荡）。
- 大地图可自由行走，城镇可自由进出，任务可拒绝、可拖延、可有多种完成方式。
- 对话采用**多分支选择**（六角菜单），一个选择会真实改变人物关系与后续事件。

> **主角区分**：
> - **自建主角**：完全自由，不受历史剧情束缚，可任意投靠、自立、游走乱世。
> - **历史人物主角**（刘备 / 曹操 / 孙策等）：拥有专属初始剧情背景，但玩家**依旧可以选择背叛原有势力、自立为王**，走出和正史不一样的走向。

### 支柱二：**成长** —— "我变强了，而且看得见"

- 角色四维属性：**体质 / 力量 / 智力 / 魅力**
- 天赋技能树：**5 大发展方向**自由加点
- 装备锻造、宝石镶嵌、宝物升金
- **命运系统**（系列招牌）：装备命运装备或招募命运人物，属性大幅跃升
- 从单枪匹马 → 领兵十人 → 指挥千军，成长梯度清晰可感

### 支柱三：**战场** —— "我不只是下命令，我亲自上阵"

- 进入战场后，**主角本人可操作参战**（砍杀、闪避、释放大招）
- 同时**指挥麾下部队**（全军突击 / 分队进攻 / 固守）
- 战前可**编辑阵型与兵种搭配**，形成"战前策略 + 战中操作"双层次
- 兵种相克 + 地形 + 天气，让每场战斗有解法

### 支柱四：**沉浸** —— "我活在三国里"

- NPC 有独立作息与反应（部分版本有记忆）
- 生活玩法：钓鱼、采药、挖矿、打猎、开宝箱
- 每位武将配**列传**，有亲密度与专属剧情
- 历史事件（官渡、赤壁、三英战吕布）与架空魔改并存

## 4. 与参考作品的差异化

我们要**继承灵魂，但不做换皮**。

| 维度 | 三国大时代3/4 | 《纪元三国》的做法 |
| --- | --- | --- |
| 美术 | 像素/复古高清混用 | **统一二次元国风**，全资源风格一致 |
| 战斗 | 军团冲锋为主 | **即时战场 + 战前阵型编辑**双层次 |
| 主角 | 3代孟获 / 4代自建 | **多主角可选**（自建 + 历史人物） |
| 手机适配 | 虚拟摇杆+按键 | 虚拟摇杆+按键 **+ 全面手势与触控优化** |
| 引导 | 教程较弱 | 内嵌新手指引 + 玩法提示系统 |
| 迁移 | 仅安卓 | 工程结构预留**多平台导出**能力 |

## 5. 玩家情绪曲线

```
好奇         紧张        成就         掌控         割据         一统
 │            │           │            │            │            │
 初入乱世 → 首次厮杀 → 首战告捷 → 拥有部队 → 占城立国 → 问鼎天下
 （探索）   （危机）    （爽感）    （成长）    （野心）    （终局）
```

设计要点：
- **前 10 分钟**必须让玩家体验到"自由行走 + 一次战斗胜利"
- **前 1 小时**必须拥有第一支部队与第一个据点
- **中后期**用势力格局变化、武将关系、隐藏结局维持长线动力

## 6. 核心玩法循环（简述）

详见《02-核心玩法循环.md》。一句话版本：

```
探索大地图 → 触发事件/接任务 → 战斗或交涉解决 → 获得资源/武将/名声
      ↑                                                        ↓
      └────── 建设城池 · 征兵练兵 · 培养武将 ←──────────────────┘
                              ↓
                        势力扩张 → 攻城占地 → 投靠 or 自立 → 一统天下
```

## 7. 不做什么（Scope Cut）

明确排除，防止范围失控：

- ❌ 不做多人联机对战（至少前两阶段不做）
- ❌ 不做 3D 建模（保持 2D，降低美术与性能成本）
- ❌ 不做抽卡氪金体系
- ❌ 不做版图实时演算的全局战争模拟（用简化势力 AI 代替）
- ❌ 首期不做 MOD 编辑器（可列为长期规划）
