# 02 · 核心玩法循环

> 《纪元三国》立项文档 · 第一阶段 框架定稿
> 版本 v0.1 | 2026-09-21

---

## 1. 三层循环结构

游戏由三个嵌套的循环构成，分别对应 **秒级手感 / 分钟级节奏 / 小时级进程**。

```
┌──────────────────────────────────────────────────────────┐
│  大循环（数小时）：势力扩张与天下格局                        │
│  ┌────────────────────────────────────────────────────┐  │
│  │  中循环（数分钟～数十分钟）：探索—战斗—成长             │  │
│  │  ┌──────────────────────────────────────────┐      │  │
│  │  │  小循环（数秒）：移动 / 攻击 / 交互           │      │  │
│  │  └──────────────────────────────────────────┘      │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

---

## 2. 小循环：即时操作（数秒）

| 环节 | 操作 | 反馈 |
| --- | --- | --- |
| 移动 | 左侧虚拟摇杆 | 主角行走/奔跑动画 |
| 交互 | 右侧确认键 | 对话、开箱、拾取、进城 |
| 战斗 | 攻击键 + 闪避键 + 大招键 | 打击音效、飘字伤害、顿帧 |
| 指挥 | 左下部队指令面板 | 部队移动/突击/固守 |

**手感目标**：单次攻击有 0.05–0.1s 顿帧 + 屏幕轻微震动 + 伤害飘字，形成"打击感"。

---

## 3. 中循环：探索—战斗—成长（数分钟）

这是玩家的**日常循环**，也是 Demo 必须验证的核心。

### 3.1 流程

```
① 在大地图自由行走
        ↓
② 触发事件（遇敌 / 遇NPC / 发现宝箱 / 进入城镇 / 随机事件）
        ↓
③ 选择处理方式
   ├─ 战斗（进入战场）
   ├─ 对话（交涉 / 接任务 / 招募 / 求婚）
   └─ 回避（绕路 / 逃跑）
        ↓
④ 结算收益
   ├─ 经验值 → 升级 → 属性点 + 天赋点
   ├─ 金钱 / 粮草 / 木材 / 铁矿
   ├─ 装备 / 宝石 / 宝物
   ├─ 武将好感度 / 名声 / 恶名
   └─ 势力关系变化
        ↓
⑤ 回到 ①（或就地补给、存档）
```

### 3.2 资源消耗闭环

玩家必须持续补给，形成张力：

| 资源 | 消耗点 | 获取点 |
| --- | --- | --- |
| 金钱 | 买装备、征兵、建设、行贿 | 任务、战斗缴获、贸易、税收 |
| 粮草 | 部队维护（按兵数/日扣） | 农田产出、购买、掠夺 |
| 兵力 | 战斗伤亡 | 征兵（需金钱+人口） |
| 精力 | 释放技能消耗 | 休息、食物、特技"奇才"自动回复 |
| 民心 | 暴政/苛税降低 | 减税、赈灾、打胜仗提升 |

**关键设计**：粮草是约束扩张的软锁——兵越多，消耗越大，逼玩家经营城池。

## 4. 大循环：势力扩张与天下格局（数小时）

### 4.1 三条成长路径

#### 路径 A：**投靠势力**（打工路线）
```
选择主公 → 完成势力任务 → 升官（兵长→校尉→将军→太守）
   → 获得封地、专属兵种、势力剧情 → 助主公一统天下 → 结局
```

#### 路径 B：**自立为王**（创业路线）
```
保持平民身份 → 积累村庄声望 + 自身名声（−恶名）
   → 声望值达标（参考大时代6：村声望+名声−恶名 > 160）
   → 收集建国信物（玉玺 + 虎符）→ 在祠堂/城池自立 → 定国号、选旗帜
   → 从一城开始扩张 → 一统天下
```

#### 路径 C：**游侠/商人**（自由路线）
```
不加入任何势力 → 靠贸易、护送、悬赏维生
   → 积累财富与人脉 → 可随时转入 A 或 B
```

### 4.2 领土扩张循环

```
拥有城池 → 内政建设（农田/商栈/兵营/学堂）→ 产出资源
   → 征兵练兵 → 组建部队 → 出征邻城
   → 战斗胜利 → 占领城池 → 领土扩大 → 循环
```

### 4.3 势力 AI（简化全局模拟）

大地图上其他势力按回合/时间自动行动：
- 征兵、攻城、结盟、宣战、招揽武将
- 玩家不参与的战斗用概率模型结算
- 定期在大地图刷新势力变化提示

## 5. 核心数值骨架（首版）

### 5.1 角色四维

| 属性 | 影响 |
| --- | --- |
| 体质 | 生命上限、体力、抗性 |
| 力量 | 物理攻击、负重、单挑伤害 |
| 智力 | 技能威力、计谋成功率、内政效率 |
| 魅力 | 招募成功率、说服、求婚、声望增长 |

### 5.2 战斗二级属性

| 属性 | 说明 |
| --- | --- |
| 攻击 | 基础伤害 |
| 防御 | 减伤 |
| 闪避 | **系列核心属性**，玩家反馈"最最重要" |
| 暴击 | 暴击率/暴击伤害 |
| 士气 | 影响部队攻防，归零则溃败 |
| 怒气 | 释放大招的能量条 |

### 5.3 数值公式（首版草案）

> ⚠️ **重要**：以下数值**仅为概念草案**。Demo 阶段优先保证**手感**，数值可以粗糙；
> 完整、平衡的数值将在**第二阶段《数值配置表》**中重新设计与调整。

```
最终伤害 = (攻击 × 技能倍率 − 防御 × 0.5) × 兵种克制系数 × 地形系数
           × 士气系数 × (1 − 闪避率) × 随机浮动(0.9~1.1)

兵种克制系数：克制 1.5 / 被克 0.67 / 同级 1.0
士气系数：士气 100 → 1.2；士气 0 → 0.5
```

> 详细数值表将在第二阶段《数值配置表》中完整展开并经平衡测试。

## 6. 时间系统

- 游戏内时间：**年 / 月 / 日**
- 战略层：以**日**为单位推进（NPC作息、事件刷新、资源结算）
- 战斗时：**实时**（不消耗游戏日，或消耗极小）

**事件刷新**：
- 每日：任务刷新、商人到访、部队维护扣粮
- 每月：市场物价波动（月初最低价）、城池产出结算
- 每年：势力格局变化、季节影响（雨季瘴气、冬季雪天）

## 7. 存档系统

- 多存档槽（参考大时代：左侧"无存档"卡片新建）
- 支持**手动存档 + 自动存档**（关键节点前自动存）
- 存档内容：角色数据、部队、城池、势力关系、任务进度、世界时间、地图状态

## 8. Demo 验证目标（第二阶段）

最小可玩 Demo 必须跑通以下闭环：

| # | 功能 | 验收标准 |
| --- | --- | --- |
| 1 | 大地图自由行走 | 摇杆控制流畅，1 张测试地图可跑 |
| 2 | 城镇进出 | 至少 1 座可进入的城，有独立场景 |
| 3 | NPC 交互 | 至少 3 个 NPC，可对话、接任务 |
| 4 | 武将招募 | 至少 1 名武将可招募入队 |
| 5 | 征兵系统 | 可消耗金钱/人口招募士兵 |
| 6 | 即时战场 | 主角 + 部队可操作，可胜可败 |
| 7 | 简单势力交互 | 至少 1 个势力可对话/接势力任务 |

**手感验收**：Demo 通关后，玩家应当反馈"这就是三国大时代的感觉"。
