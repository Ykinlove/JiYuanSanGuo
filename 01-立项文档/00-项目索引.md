## 一、项目一句话定位

《纪元三国》是一款 **开放沙盘三国策略RPG** 安卓手机游戏：玩家在无缝大地图上自由行走、进出城镇、结交NPC、招募武将、征兵练兵，可投靠魏蜀吴群雄或自立为王，进入战场后亲手参战并指挥部队，最终在乱世中书写属于自己的传奇。

**对标作品**：《三国大时代3·南蛮入侵》《三国大时代4·霸王立志》（昆明梵乐塔科技）

| 决策项 | 结论 | 备注 |

| 游戏类型 | 开放沙盘三国策略RPG（SLG + RPG 混合） | 完全对标三国大时代系列 |

| 主角 | **多主角可选** | 自建角色 + 历史人物（刘备/曹操/孙策等） |
| 战斗 | **即时战场 + 战前阵型编辑** | 主角亲自参战 + 指挥部队，兵种相克 + 阵型双维度 |

| 联网 | 单机离线优先 | 云存档暂不做 |
| 首个Demo区域 | **南中** | 山地/丛林/村寨地形丰富，南蛮题材特色鲜明 |

> **关键坑：Godot 4 横屏枚举值**。`display/window/handheld/orientation=1` 是 Godot 3 时代的横屏写法，
> 在 4.7 导出后映射成 Android `screenOrientation=1`（**竖屏 PORTRAIT**）；=2 映射成 8（reverseLandscape，朝向反）。
> 实测 **=4 → 11 userLandscape（横屏 + 重力双向）**，=7 → 0 固定 landscape。本工程定案 **=4**，并由 `_verify_m8.py` 锁定，杜绝误改回 1/2。

> swiftshader 软渲 `GL_MAX_FRAGMENT_UNIFORM_VECTORS=261` 会让 Godot 画布着色器全部链接失败只出灰屏——非游戏缺陷，真 GPU 普遍 ≥1024）：
> 开机 splash → 主菜单（横屏布局/美术/按钮命中正常，版本号改为读 project.godot）→ 新的征程 →
> 大地图（HUD 资源/年月、小地图、建宁城弹窗、开场旁白触屏推进）→ 城池内景（建筑/NPC/演武入口）→
> 演武场选择 → 战前布阵（阵型/阵位/战力预估）全部渲染与触控正常，无 GDScript 报错；
> 战场/单挑弹层因新档兵力为 0 未在本机走到，其布局由静态尺寸校验与 M7 桌面探针覆盖，待真机补录。
