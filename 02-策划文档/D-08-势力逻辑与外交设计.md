## 一、三成长路径细化

参考 [02-核心玩法循环 §4.1](../01-立项文档/02-核心玩法循环.md) 的三路径骨架，本设计细化每路径的触发条件、阶段划分、阶段奖励、退出/转换机制。

### 1.1 路径概览

| 路径 | 触发条件 | 主导数值 | 阶段数 | 阶段间介质 |
| --- | --- | --- | --- | --- |
| **A 投靠** | 与目标势力关系值 ≥30 + 触发投靠剧情 | 名声 + 亲密度 | 4 阶段（兵长→校尉→将军→太守） | 功勋 |
| **B 自立** | 未加入任何势力 + 声望达标 + 建国信物齐 | 村庄声望 + 名声 - 恶名 | 5 阶段（平民→义士→乡绅→豪强→自立） | 声望 |
| **C 游侠** | 未加入任何势力 + 拒绝投靠/自立 | 财富 + 人脉 | 3 阶段（游侠→侠士→侠豪） | 财富 |

### 1.2 路径 A · 投靠势力

#### 1.2.1 阶段划分

| 阶段 | 官职 | 解锁条件 | 享有的权力 |
| --- | --- | --- | --- |
| A1 | 兵长 | 投靠成功 | 领兵 500，受军令调遣 |
| A2 | 校尉 | 累积功勋 ≥100 | 领兵 1000，可独立接势力任务 |
| A3 | 将军 | 累积功勋 ≥300 + 主角亲密度 ≥50 | 领兵 2000，可封地一座，参与势力决策 |
| A4 | 太守 | 累积功勋 ≥600 + 主角亲密度 ≥80 + 势力主城数 ≥3 | 领兵 3000，封地 1 郡，可独断一方军事 |

#### 1.2.2 升官结算

- **功勋来源**：完成势力任务（+10~50）、参与势力战役（+20~100）、贡献金钱/装备/资源（金钱 100→+1）、推荐武将入伙（+10/人）。
- **升官触发**：累积功勋达阈值时，下个时间月（次月 1 日）触发升官剧情，主角（势力君主）召见，授官印，发放专属兵种权限。
- **降级机制**：连续 3 月无任何功勋贡献，扣 10% 当前功勋，第 4 月触发降级警告，第 6 月实际降级一阶。

#### 1.2.3 退出/转换

- **退出**：玩家可主动请辞，降为平民身份；保留已获封地，但失去兵权与官职特权。
- **叛变**：与原势力关系降至 -50 以下，可叛变至他势力；触发原势力追杀事件链。
- **转换路径 B**：满足自立条件后，可请辞转自立；原势力关系自动降至 -30（视为背叛）。

### 1.3 路径 B · 自立为王

详见 [D-09 自立与投靠机制设计](D-09-自立与投靠机制设计.md)。本档仅列高层接口：

- 触发：村庄声望 + 名声 - 恶名 > 160 + 玉玺/虎符信物齐 + 主角未加入任何势力。
- 流程：祠堂自立 → 定国号 → 选旗帜 → 都城升格 → 自立成功。
- 自立后：成为新势力（faction_id 由 factions6 新分配），开始与其他势力正面博弈。

### 1.4 路径 C · 游侠/商人

#### 1.4.1 阶段划分

| 阶段 | 称号 | 解锁条件 | 享有的特权 |
| --- | --- | --- | --- |
| C1 | 游侠 | 拒绝投靠/自立后默认 | 可接普通委托任务 |
| C2 | 侠士 | 累积财富 ≥5000 + 人脉（结识武将 ≥20） | 可接护送任务、解锁悬赏 |
| C3 | 侠豪 | 累积财富 ≥20000 + 人脉（结识武将 ≥50）+ 名声 ≥50 | 可开商铺、影响市场物价、触发隐居结局 |

#### 1.4.2 转换

- 转 A：满足投靠条件，可随时转投靠；游侠阶段财富转化为初始资金。
- 转 B：满足自立条件，可转自立；游侠阶段结识的武将可召为班底。
- 终结：游侠不强制终结，可全程游侠到结局。

### 1.5 路径转换矩阵

| 起 \ 转 | A 投靠 | B 自立 | C 游侠 |
| --- | --- | --- | --- |
| A 投靠 | — | 可转（原势力关系 -30） | 可转（请辞降平民） |
| B 自立 | 不可（已自立） | — | 不可（自立后不可逆） |
| C 游侠 | 可转 | 可转 | — |

## 二、势力 AI 高层决策

参考 [04 §3.3 势力 AI 开发约束](../01-立项文档/04-地图势力与城池体系.md)：势力 AI **仅处理高层全局决策**，不做微观操控。

### 2.1 AI 决策周期

- **决策频率**：每月 1 次（月初结算时）。
- **决策范围**：征兵、攻城、结盟、宣战、招揽武将、内政建设。
- **决策依据**：当前势力状态（兵力/粮草/金钱/城池数/关系值）+ 周边势力状态 + 时间主线进度。

### 2.2 决策类型与概率公式

#### 2.2.1 征兵决策

```
trigger: 兵力 < 阈值（城池数 × 1000 + 500）
probability = clamp(0.3 + (金钱/3000) + (人口/10000), 0, 0.95)
priority: 每月最多 1 次，按势力排序逐个结算
```

征兵数量 = min(可征容量, 需求缺口)。城池等级越高，可征容量越大（参考 M5 民心机制）。

#### 2.2.2 攻城决策

```
trigger: 兵力 > 目标城守军 × 1.5 + 与目标城势力关系 ≤ -50
probability = clamp(0.2 + (兵力比 - 1.5) × 0.3 + (好战度/100), 0, 0.85)
target_priority: 关隘 > 渡口 > 主城 > 一般城
```

- 好战度：势力特性，0~1，参考 [factions6 raw_extra.col10]。
- 主城不被 AI 主动攻取（需玩家参与），除非该势力已亡一半城池。

#### 2.2.3 结盟决策

```
trigger: 与目标势力关系 ≥60 + 周边存在共同敌对势力
probability = clamp(0.3 + (关系值 - 60)/100, 0, 0.7)
维持: 每月消耗双方关系值 -2（结盟维护）
```

#### 2.2.4 宣战决策

```
trigger: 与目标势力关系 ≤ -80 + 自身兵力 > 目标 × 0.8
probability = clamp(0.5 + (好战度 × 0.3), 0, 0.9)
```

#### 2.2.5 招揽武将决策

```
trigger: 自身武将数 < 城池数 × 2 + 周边存在无主/低归属武将
probability = clamp(0.4 + (名声/200), 0, 0.6)
target: 无主武将 > 关系值低势力武将 > 玩家麾下武将（亲密度 <50 时尝试）
```

#### 2.2.6 内政建设决策

```
trigger: 金钱 > 城池数 × 500 + 某城建筑位空缺
priority: 农田（粮草紧缺时）> 兵营（兵力紧缺时）> 商栈（金钱紧缺时）> 学堂 > 城墙
```

### 2.3 AI 战斗结算（概率模型）

参考 [02 §4.3](../01-立项文档/02-核心玩法循环.md)：玩家不参与的战斗用概率模型结算。

```
胜率 = clamp(
  (己方兵力 - 守方兵力 × 城防系数) / (己方兵力 + 守方兵力 × 城防系数) × 0.5 + 0.5
  + (己方主将四维均 - 守方主将四维均) × 0.01
  + 兵种克制系数 × 0.1,
  0.05, 0.95
)
城防系数 = 1 + 城防等级 × 0.1
```

战斗结果：
- 胜方：占领城池（守方兵力减 80%，胜方兵力减 30%），城防降 1 级，民心 -20。
- 败方：兵力减 50%，关系 -20，触发"溃败"状态 1 月。

## 三、外交 7 手段

参考 [04 §3.3 外交手段](../01-立项文档/04-地图势力与城池体系.md)：结盟、通商、宣战、联姻、离间、造谣、破坏。

### 3.1 关系值状态机

| 关系值 | 状态 | 可用外交手段 |
| --- | --- | --- |
| 80~100 | 同盟 | 借兵、通商、共同作战、联姻 |
| 30~79 | 友好 | 通商、贸易、联姻（高关系时） |
| -29~29 | 中立 | 通商、招揽武将 |
| -79~-30 | 敌对 | 拒绝对话、可能袭击、宣战前置 |
| -100~-80 | 死敌 | 主动宣战、追杀、破坏 |

### 3.2 七手段规则

#### 3.2.1 结盟

- **前置**：双方关系 ≥60 + 双方未与对方敌对势力结盟。
- **操作**：派使者（需武将，魅力 ≥50）+ 礼物（金钱 ≥1000）。
- **效果**：双方关系 +20，进入同盟状态。可借兵（一次 ≤500 兵）、通商免税、共同作战（自动参战）。
- **维持**：每月双方关系 -2（消耗），任一方主动毁约 → 关系 -40 + 信誉 -10。
- **失败概率**：clamp(0.5 - (魅力/200) - (礼物价值/5000), 0.05, 0.7)。

#### 3.2.2 通商

- **前置**：双方关系 ≥0 + 双方有商栈建筑。
- **操作**：派商人（需武将，智力 ≥40）+ 货物。
- **效果**：双方关系 +2/月，物价 -5%（区域内），双方金钱 +200/月。
- **维持**：每月自动持续，任一方关系 <0 时终止。
- **失败概率**：clamp(0.3 - (智力/300), 0, 0.3)。

#### 3.2.3 宣战

- **前置**：双方关系 ≤-30 + 玩家势力决策（或 AI 决策）。
- **操作**：发檄文（自动），无需使者。
- **效果**：双方关系 -50，进入战争状态。双方互攻对方城池，AI 自动结算（参考 §2.3）。
- **退出**：任一方主动求和（需金钱 ≥3000 + 关系修复 +20），或一方主城被攻破。
- **失败概率**：0（必成）。

#### 3.2.4 联姻

- **前置**：双方关系 ≥70 + 双方有适婚女性武将（heroes6.interaction_class=1 + 性别字段，M11 补字段）。
- **操作**：派使者（需武将，魅力 ≥60）+ 聘礼（金钱 ≥2000）。
- **效果**：双方关系 +30，进入"姻亲"状态（强同盟，关系值 -1/月，比同盟慢），女性武将移籍对方势力。
- **维持**：长期持续，关系值不易下降，但任一方违约 → 关系 -60 + 信誉 -20。
- **失败概率**：clamp(0.4 - (魅力/200) - (聘礼价值/10000), 0.1, 0.6)。

#### 3.2.5 离间

- **前置**：目标势力有 ≥2 名武将 + 玩家智力 ≥60。
- **操作**：派密探（需武将，智力 ≥70）+ 金钱 ≥500。
- **效果**：成功时目标势力内部忠诚 -10，随机 1 名武将关系 -20，极端情况下武将出奔。
- **失败概率**：clamp(0.6 - (智力/200) - (金钱/3000), 0.15, 0.85)。
- **被发现概率**：clamp(0.3 + (目标势力君主智力/300), 0.1, 0.5)。被发现 → 关系 -30。

#### 3.2.6 造谣

- **前置**：目标势力名声 ≥30 + 玩家智力 ≥50。
- **操作**：派密探（需武将，智力 ≥60）+ 金钱 ≥300。
- **效果**：成功时目标势力名声 -10、民心 -5、邻势力关系 -5。
- **失败概率**：clamp(0.5 - (智力/200), 0.1, 0.7)。
- **被发现概率**：clamp(0.4 + (目标势力君主智力/300), 0.15, 0.6)。被发现 → 关系 -20 + 名声 -5。

#### 3.2.7 破坏

- **前置**：与目标势力关系 ≤-30 + 玩家武力 ≥50。
- **操作**：派密探（需武将，武力 ≥70 + 智力 ≥50）+ 金钱 ≥800。
- **效果**：成功时目标势力随机 1 城降级（建筑 -1 级 或 粮草 -50% 或 兵力 -10% 或 城防 -1 级）。
- **失败概率**：clamp(0.55 - (武力/200) - (智力/400), 0.2, 0.8)。
- **被发现概率**：clamp(0.5 + (目标势力君主智力/300), 0.2, 0.7)。被发现 → 关系 -40 + 进入敌对状态。

### 3.3 外交使者要求汇总

| 手段 | 使者属性 | 门槛 | 资源门槛 |
| --- | --- | --- | --- |
| 结盟 | 魅力 | ≥50 | 金钱 ≥1000 |
| 通商 | 智力 | ≥40 | 货物 |
| 宣战 | — | — | — |
| 联姻 | 魅力 | ≥60 | 金钱 ≥2000 + 适婚女将 |
| 离间 | 智力 | ≥70 | 金钱 ≥500 |
| 造谣 | 智力 | ≥60 | 金钱 ≥300 |
| 破坏 | 武力+智力 | 武 ≥70 + 智 ≥50 | 金钱 ≥800 |

## 四、GameState 字段规划

参考 [04 §3.1 势力数据结构](../01-立项文档/04-地图势力与城池体系.md)，GameState 需新增以下字段（M12+ 实装）：

```gdscript
# 投靠路径
var affiliation: int = 0          # 所属势力 id（0=无）
var official_rank: int = 0         # 官阶 0-4（平民/兵长/校尉/将军/太守）
var merit: int = 0                 # 累积功勋

# 自立路径
var village_fame: int = 0          # 村庄声望
var fame: int = 0                  # 名声
var infamy: int = 0                # 恶名
var has_jade_seal: bool = false    # 玉玺
var has_tiger_tally: bool = false  # 虎符
var is_self_rule: bool = false     # 是否已自立

# 游侠路径
var wealth: int = 0                # 累积财富
var acquaintances: Array[int] = [] # 结识武将 id 列表

# 势力关系（M5 已有 faction_relations）
# var faction_relations: Dictionary  # {faction_id: relation_value}，已存在
```
