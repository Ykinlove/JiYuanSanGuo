### 1.2 设计原则

1. **由南向北推进**：玩家开局区域随主角线变化（刘→荆州、曹→中原、孙→江东），主线推进方向统一为南→北。
2. **三线同章异轨**：每章对刘曹孙三条主角线设计不同开局场景、不同关键抉择与不同终态，但章节时间锚点统一。
3. **自建主角走"刘式仁义线"**：自建主角无固定出身，开局默认走刘备式草根路径，可在第 2 章末选择投靠任一历史主角。
4. **只写骨架不写对话**：本档仅列章节结构、分支点、引用资源 id；具体对话/旁白/六角菜单选项文本在 M11+ 逐章补。
5. **数据表引用闭合**：所有引用的城池 id 存在于 [cities.json](../04-Demo/assets/data/cities.json)、势力 id 存在于 [factions6.json](../04-Demo/assets/data/factions6.json)、武将 id 存在于 [heroes6.json](../04-Demo/assets/data/heroes6.json)。

## 二、第一章 · 黄巾之乱（184 年）

### 2.1 关键事件

1. **开局旁白**：大汉气数将尽，太平道张角起义，号"苍天已死，黄天当立"。十常侍乱政，民不聊生。
2. **何进募兵令**：大将军何进传檄天下，征义军讨黄巾。
3. **三线起点分歧事件**：玩家根据所选主角进入不同开局场景。
4. **黄巾主力决战**：在广宗/下博等地与张角三兄弟决战。
5. **黄巾残部南下**：部分黄巾残部遁入南中，与当地蛮族合流，为 M11 南中支线埋点。
6. **章末**：张角病死/战死，黄巾主力覆灭。汉朝论功行赏，三线主角获得初始官职。

## 三、第二章 · 董卓之乱（189–192 年）

### 3.1 关键事件

1. **灵帝驾崩**：少帝即位，何进与十常侍争权。
2. **何进被诛**：何进被十常侍诱杀，袁绍率军入宫诛宦官。
3. **董卓进京**：董卓趁乱入洛阳，废少帝立献帝，独揽朝政。
4. **丁原 vs 董卓**：丁原反抗董卓，吕布受唆使杀丁原投董。
5. **诸侯讨董**：曹操发檄，袁绍为盟主，刘曹孙三线会盟酸枣。
6. **汴水之战**：曹操独立追击董卓，败于徐荣。
7. **火烧洛阳 + 迁都长安**：董卓挟献帝迁都，火烧洛阳。
8. **吕布刺董**（192）：王允连环计，吕布刺董卓，董卓势力分裂为李傕郭汜。
9. **章末**：三线主角离开洛阳/长安，各自开始独立发展。

## 四、第三章 · 群雄割据（190–199 年）

### 4.1 关键事件

1. **曹操迎帝都许**（196）：曹操迎献帝迁都许昌，挟天子以令诸侯。
2. **吕布袭徐州**：刘备投陶谦，陶谦三让徐州，刘备领徐州。吕布被曹操击破后投刘备，反客为主袭取徐州，刘备投曹操。
3. **孙策平江东**：孙策以传国玉玺质于袁术借兵，渡江转战江东，败刘繇、严白虎、王朗，奠定孙吴基业。
4. **袁术称帝败亡**：袁术寿春称帝，遭到诸侯围攻，败亡投奔部曲雷薄陈兰，呕血而死。
5. **袁绍定河北**：袁绍破公孙瓒，统一河北四州，势力达到顶峰。
6. **张绣反复**：张绣南阳降曹又反，宛城之战曹操败丧子曹昂（虚构：玩家可救/不救）。
7. **章末**：曹操、袁绍隔黄河对峙，赤壁前夜之势形成。

### 9.1 章节间过渡机制

- **章节触发条件**：每章触发需满足主线任务链完成度 + 时间锚点（游戏年内时间到达）+ 玩家主角势力状态（投靠/自立/游侠）。
- **章间过场**：每章末播放过场动画（旁白 + 关键事件图），引出下一章主线。
- **分支记忆**：玩家在前面章节的抉择会以 GameState 分支标志位形式保留，影响后续章节 NPC 反应、势力关系、结局分支。
- **未触发章节处理**：若玩家在某章抉择偏离主线（如长期游侠），章节触发条件会延迟，但最终仍会推进（避免卡死）。
