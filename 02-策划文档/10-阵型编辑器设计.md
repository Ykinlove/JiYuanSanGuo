# 阵型编辑器设计说明

> 《纪元三国》差异化核心系统 · M3
> 版本 v1.0 | 2026-09-21

---

## 一、为什么这是核心卖点

对标《三国大时代3·南蛮入侵》《三国大时代4·霸王立志》，原作的阵型系统停留在**战前选择一个阵型名**，
加成是全局的、静态的。我们在 M3 把它做深一层：

1. **阵型 ≠ 只选名字**：3×5 阵位网格，每支部队要**摆放位置**
2. **位置有独立加成**：同一支部队放前排还是后排，数值完全不同
3. **兵种 × 阵位 × 相克 三维联动**：弓兵放前排 = 灾难，枪兵放前排 = 反骑墙
4. **实时战力预估**：改一个阵位，右上角战力数字立刻变，玩家能直观看到"这样摆更强"

这套设计让"战前准备"本身成为一个**有决策深度的玩法**，而不是走过场。

## 二、3×5 阵位网格

```
        列1    列2    列3    列4    列5
      ┌──────┬──────┬──────┬──────┬──────┐
前军  │ 左锋 │ 左翼 │ 中锋 │ 右翼 │ 右锋 │   ← 贴近敌军，承受第一波冲击
      ├──────┼──────┼──────┼──────┼──────┤
中军  │ 左卫 │ 左辅 │ 中坚 │ 右辅 │ 右卫 │   ← 主力接战区
      ├──────┼──────┼──────┼──────┼──────┤
后军  │ 左辎 │ 左帐 │ 中帐 │ 右帐 │ 右辎 │   ← 指挥与远程，需前排保护
      └──────┴──────┴──────┴──────┴──────┘
                                          ↑ 我方大营
```

### 阵位加成表

| 阵位类别 | 攻击 | 防御 | 说明 |
| --- | --- | --- | --- |
| **前排·中锋**（col3） | +25% | −15% | 冲阵位，最高攻击，但战损最快 |
| **前排·锋翼**（col1/5） | +15% | −10% | 包抄位，配合鹤翼阵有额外加成 |
| **前排·翼位**（col2/4） | +12% | −8% | 常规接战位 |
| **中军·中坚**（col3） | +5% | +10% | 攻守均衡 |
| **中军·辅位**（col2/4） | +8% | +5% | 侧援位，机动支援 |
| **中军·卫位**（col1/5） | 0% | +12% | 护翼，防侧击 |
| **后排·中帐**（col3） | −10% | +25% | 主帅位，统帅加成翻倍 |
| **后排·帐位**（col2/4） | −5% | +20% | 远程射击位 |
| **后排·辎位**（col1/5） | −15% | +30% | 辎重位，弓兵最佳，但无近战保护 |

> 设计意图：**没有"万能摆法"**。把弓兵放后排是常识，但后排攻击 −10%，
> 如果敌方没有骑兵突进，把弓兵推到前排反而输出更高 —— 决策依赖于对敌情的判断。

## 三、行 × 兵种协同加成

除了阵位加成，还有**行-兵种匹配**的额外修正：

| 行 | 适配兵种 | 额外加成 | 不适配惩罚 |
| --- | --- | --- | --- |
| 前军 | 步兵 / 枪兵 | 防御 +10%（"列阵如墙"） | 弓兵/弩兵：攻击 −25%（"暴露"） |
| 中军 | 骑兵 / 精英 | 攻击 +8%（"蓄势待发"） | 无 |
| 后军 | 弓兵 / 弩兵 | 攻击 +15%（"居高临下"） | 骑兵：速度 −20%（"无冲击空间"） |

**组合示例 —— 反骑阵**（敌方多骑兵）：
```
枪兵 枪兵 枪兵 枪兵 枪兵   ← 整排枪阵，对骑兵 +10% 防御
步兵 骑兵 步兵 骑兵 步兵   ← 中军机动反击
弓兵 弓兵 弓兵 弓兵 弓兵   ← 后排输出
```
配合「方圆阵」防御 +20%，这套摆法对阵纯骑兵几乎无解。

**组合示例 —— 突击阵**（敌方多弓兵）：
```
骑兵 骑兵 骑兵 骑兵 骑兵   ← 前排骑兵冲锋，但骑兵放前排无适配加成
步兵 步兵 步兵 步兵 步兵
弓兵 弓兵 弓兵 弓兵 弓兵
```
配合「锋矢阵」冲锋 +25%，一波冲散敌方后排。

## 四、战力预估公式

```
单支部队战力 =
    count                    兵力基数
  × (1 + attack_bonus)       阵型全局攻击加成
  × (1 + slot_attack_bonus)  阵位攻击加成
  × (1 + row_match_bonus)    行-兵种协同加成
  × unit_quality             兵种品质系数（attack + hp/10）/ 30
  × hero_multiplier          统兵武将加成（若有）

总战力 = Σ 各部队战力
胜率预估 = f(我方总战力 / (我方总战力 + 敌方总战力))
```

### 统兵武将加成

若某部队的武将（`hero_id`）四项属性中的**统率**（用 intelligence + charisma 均值近似）较高：

```
hero_multiplier = 1.0 + min(0.30, (统率 - 50) / 200)
```

> 50 为基准值。统率 50 → ×1.0；统率 110 → ×1.30（上限）。

## 五、操作流程（手机横屏）

```
【阵型选择】底部横排 6 个阵型按钮，点击切换，右侧实时显示该阵型加成
      ↓
【部队上阵】左侧「可用部队」列表中点击一支部队 → 选中状态
      ↓
【放置阵位】点击 3×5 网格中任一格 → 部队落位（若该格已有部队则互换）
      ↓
【查看加成】鼠标/手指悬停或点击格子 → 顶部信息栏显示该格详情
      ↓
【实时预估】右上角战力与胜率随每次操作立即刷新
      ↓
【开 战】「开战」按钮 → 写入 GameState.formation_slots → 进入战场
```

### 触屏适配

- 网格格子在 1920×1080 下为 **220×150 px**，远超 48×48dp 最小点击区要求
- 部队卡片 **260×86 px**
- 所有按钮 **≥ 80px 高**
- 使用 `TouchScreenButton` 语义（普通 Button + `custom_minimum_size` 保证命中区）

## 六、与传统做法的对比

| 维度 | 原版三国大时代 | 纪元三国 M3 |
| --- | --- | --- |
| 阵型选择 | 战前选一个名字 | 选名字 + 15 个阵位逐一配置 |
| 位置影响 | 无 | 9 类阵位独立攻防加成 |
| 兵种协同 | 仅相克 | 相克 + 行适配 + 阵位适配 |
| 反馈 | 无预估 | 实时战力 + 胜率预估 |
| 决策深度 | 1 次选择 | 15 次摆位决策 |

这就是"做深一层"的意义：**同样的题材，多一层的策略空间**。

## 七、开发约束

1. **不引入新美术依赖**：网格与部队卡片用 `ColorRect` + `Label` 程序化绘制，
   贴图就绪后可替换为 `TextureRect`（预留 `assets/sprites/ui/formation/` 目录）
2. **纯数据驱动**：阵位加成定义在 `formation_slots.json`，改数值不用改代码
3. **可跳过**：不做任何配置也能直接「开战」，此时用默认阵型 + 自动摆位，
   保证不阻断快节奏玩家
4. **状态持久化**：配置结果写入 `GameState.formation_id` 与 `formation_slots`，
   随存档保存

## 八、后续扩展（M3 之后）

- 阵型熟练度：同一阵型使用次数达标 → 解锁阵型强化
- 敌军侦察：情报等级高时可见敌方阵型，可针对性布阵
- 地形联动：山地/水泽对特定阵位有额外修正
- 武将特技联动：某些特技在特定阵位触发（如"中帐"位武将获得统帅光环）
