## 一、声望系统数值

### 1.1 声望公式（参考大时代 6）

参考 [04 §5.2 声望公式](../01-立项文档/04-地图势力与城池体系.md)：

```
自立判定值 = 村庄声望 + 自身名声 − 自身恶名
自立阈值 = 160
```

- 村庄声望（village_fame）：在某一村庄累积的局部声望，每村庄独立计数。
- 名声（fame）：全局声望，影响 NPC 态度、招降成功率、招揽响应。
- 恶名（infamy）：负面行为累积，影响民心、被追杀概率。

### 1.2 声望获取途径

#### 1.2.1 村庄声望（village_fame）

| 行为 | 效果 | 备注 |
| --- | --- | --- |
| 完成村民/酒店老板委托 | +1/任务 | **重要约束**：接任务后需等 ≥3 游戏日交付才计数（防速刷） |
| 帮村民击败山贼/黄巾 | +2/次 | 单村庄每月上限 5 次 |
| 施赈（金钱 200→民心 5） | +1/次 | 单村庄每月上限 3 次 |
| 修缮村寨建筑 | +3/次 | 单村庄每月上限 1 次 |

- 上限：每村庄声望 0~100。
- 衰减：村庄声望每月自然 -1（长期不互动则被遗忘）。
- 自立阈值需要累计：在目标村庄声望 ≥80 才可触发自立（"乡绅"地位）。

#### 1.2.2 名声（fame）

| 行为 | 效果 | 备注 |
| --- | --- | --- |
| 野外消灭山贼/黄巾 | +1/次 | 上限 100 |
| 击败敌对势力武将 | +5/次 | 主线关键战役翻倍 |
| 完成势力任务 | +2/次 | 投靠势力时 |
| 完成生活采集任务 | +1/次 | 钓鱼/采药/挖矿等 |
| 招降敌将 | +10/次 | 高魅力成功率 |
| 打劫/屠村 | -5/次 | 转恶名途径 |

#### 1.2.3 恶名（infamy）

| 行为 | 效果 | 备注 |
| --- | --- | --- |
| 打劫（NPC/商队） | +1/次 | 上限 100 |
| 屠村（攻城后选择屠戮） | +10/次 | 严重恶行 |
| 杀俘（处决战俘） | +5/次 | 参考俘虏系统 |
| 毁约（结盟/联姻后违约） | +5/次 | 外交信誉受损 |
| 叛变（投靠后叛变） | +10/次 | 信誉 -20 |

- 恶名 ≥30：触发"恶名昭著"状态，部分 NPC 拒绝交互。
- 恶名 ≥60：触发"全民唾弃"状态，被朝廷通缉，城池民心 -10/月。
- 恶名 ≥80：触发"天下共击"状态，各势力主动宣战（参考 [D-08 §2.2.4](D-08-势力逻辑与外交设计.md)），触发自立失败结局风险（→ §5.3 失败结局）。

### 1.3 声望状态机

| 自立判定值 | 状态 | 可触发的剧情 |
| --- | --- | --- |
| 0~50 | 平民 | 接受委托任务 |
| 50~100 | 义士 | 接受护送任务、低级势力任务 |
| 100~160 | 乡绅 | 触发"乡里举荐"事件，可入仕 |
| ≥160 + 信物齐 | 豪强 | 可触发祠堂自立剧情 |

## 三、立业流程

参考 [04 §5.3](../01-立项文档/04-地图势力与城池体系.md) "祠堂自立 → 定国号 → 选旗帜 → 都城升格"。

### 3.1 立业触发条件

全部满足才可触发：

1. 主角未加入任何势力（affiliation=0）。
2. 在某村庄声望 ≥80。
3. 自立判定值 = village_fame + fame - infamy ≥160。
4. has_jade_seal=true 且 has_tiger_tally=true。
5. 主角未处于"天下共击"状态（恶名 <80）。
6. 至少有 1 名亲密度 ≥50 的武将跟随（建国班底）。

### 3.2 立业流程详细

```
[Step 1] 在该村庄的祠堂/指定城池触发"自立剧情"
   → 选择"举义旗"或"再思量"
   → 选"举义旗"进入流程

[Step 2] 定国号
   → 玩家输入国号（≤4 字符，过滤敏感词）
   → 系统自动生成可选国号建议（如 "蜀汉"、"大燕"、"凉"）
   → 玩家确认

[Step 3] 选旗帜
   → 弹出旗帜选择面板（5 色旗 × 5 图案 = 25 选项）
   → 玩家确认
   → 旗帜纹样绑定 GameState.self_rule_flag

[Step 4] 都城升格
   → 该村庄/城池等级 +2，is_capital=true
   → 触发"百官朝贺"剧情，初始班底武将入朝
   → GameState.is_self_rule=true
   → factions6 新建条目，分配 faction_id（参考现有最大 id+1）
   → 该村庄/城池与周边 1 城/据点归属玩家势力

[Step 5] 自立成功结算
   → 全势力关系 -10（视为新竞争对手）
   → 名声 +50、村庄声望清零（转化为 fame）
   → 解锁自立专属剧情线与结局
```

### 3.3 自立后行为

- **国号与旗帜**：玩家可后续修改（每次 1000 金钱 + 关系 -5）。
- **君主称号**：默认"主公"，可自定义（如"王"、"帝"）。
- **势力博弈**：解锁 [D-08 §2 势力 AI](D-08-势力逻辑与外交设计.md) 全部外交手段，玩家势力参与月决策。
- **专属剧情**：参考 [D-02 第 6-7 章](D-02-主线剧情剧本骨架.md)，自立线主角主导统一进程。

## 四、投靠升官与封地规则

参考 [D-08 §1.2 路径 A](D-08-势力逻辑与外交设计.md) 四阶段（兵长→校尉→将军→太守）。本档细化封地与专属兵种。

### 4.1 封地规则

| 官阶 | 可封地数 | 封地来源 | 封地权限 |
| --- | --- | --- | --- |
| 兵长（A1） | 0 | — | 无封地 |
| 校尉（A2） | 0 | — | 无封地 |
| 将军（A3） | 1 | 势力主赏赐（从势力现有城池挑 1 座一般城） | 该城产出 50% 归玩家 |
| 太守（A4） | 1 郡（3-5 城） | 势力主分封（从势力现有郡挑 1 郡） | 该郡产出全归玩家，可独断一方军事 |

### 4.2 封地权限

- **产出归己**：封地内农田/商栈/兵营产出按比例归玩家，不再上交势力。
- **任命守将**：可在封地任命守将（从玩家麾下武将挑选）。
- **建设权**：可在封地内自由建设（参考 [04 §4.2 内政建设](../01-立项文档/04-地图势力与城池体系.md)）。
- **税收**：太守可调整封地税率（参考 M5 民心机制，高税降民心）。
- **征兵**：可在封地内独立征兵（参考 M5 民心消耗）。
- **军事权**：将军级仅可领兵参与势力战役，太守级可独断封地内军事（攻邻城需势力主批准）。

## 五、结局分支

参考 [D-02 §10 三线结局汇总](D-02-主线剧情剧本骨架.md) 各线结局，本档补充失败结局与触发条件。

### 5.1 投靠线结局

| 结局 id | 触发条件 | 结局描述 |
| --- | --- | --- |
| affiliation_ending_a | 跟随主公主导统一（第 7 章改写路径） | 与所投势力共治天下，封王拜相，史册留名 |
| affiliation_ending_b | 主公势力亡于他势力（第 6-7 章） | 玩家可选：①跟随主公殉国 ②叛变他势力续命 ③隐退为平民 |
| affiliation_ending_c | 主角被俘处决（恶名 ≥60 + 主公关系 <50 时被献祭） | 主角被主公献祭求和，触发"忠义殒命"结局 |
| affiliation_ending_d | 全程恶名 ≥80 | 主角暴政引发部曲叛变，被诛杀，史册骂名 |

### 5.2 自立线结局

| 结局 id | 触发条件 | 结局描述 |
| --- | --- | --- |
| self_ending_a | 完成自立，第 7 章主导统一 | 自建势力一统天下，开创新朝，玩家为开国君主 |
| self_ending_b | 自立后势力覆灭（被攻破主城） | 主角自尽殉国，史册"昙花一现" |
| self_ending_c | 自立后被俘处决（恶名 ≥80 触发天下共击 + 兵力 <敌对联军×0.5） | 主角被俘处决，势力瓦解，史册"叛贼伏诛" |
| self_ending_d | 自立后主动投降 | 主角投降他势力，受封闲职，史册"识时务者" |
| self_ending_e | 全程恶名 ≥100 | 触发"天人共愤"事件，主角暴毙，势力瓦解 |

### 5.3 游侠线结局

| 结局 id | 触发条件 | 结局描述 |
| --- | --- | --- |
| ranger_ending_a | 财富 ≥20000 + 名声 ≥50 + 不投靠不自立 | 隐居江湖，留名青史，"侠之大者" |
| ranger_ending_b | 全程财富 <5000 | 江湖湮没无闻，"草莽一生" |
| ranger_ending_c | 恶名 ≥80 | 被通缉追杀，死于非命，"恶贯满盈" |
| ranger_ending_d | 第 7 章前转投靠/自立 | 进入对应路径结局 |

### 5.4 失败结局通用规则

参考 [02 §7 存档系统](../01-立项文档/02-核心玩法循环.md)，失败结局触发后：

- **不强制结束游戏**：玩家可选择从最近存档重玩，或继续以"败北"状态探索。
- **失败结局存档**：标记 `ending_triggered=true`，避免重复触发。
- **失败结局后允许内容**：可继续游戏但不可触发其他结局，NPC 反应改为"败者"对话。

### 5.5 结局触发判定时序

```
玩家死亡 / 主城被攻破 / 主角被俘 →
    检查结局触发条件 →
        满足失败结局 → 触发对应结局，标记 ending_triggered
        不满足 → 进入"败北"状态，允许重玩或继续
```
